## 3. RENDERING: COME L'ETERE DIVENTA MATERIA

### 3.1. Pipeline di rendering

```
1. GENERAZIONE DELL'INTENZIONE (Osservatore)
   neuroni → impulsi → pattern di intenzione
2. QUERY BPF
   "trova varianti dove [OBIETTIVO] = TRUE"
3. APPLICAZIONE DEL PESO
   P_final = P₀ × W(O) × Risonanza
4. SELEZIONE DELLA VARIANTE
   argmax(P_final)
5. COSTRUZIONE DELLA STORIA
   backdating: genera il passato della variante
6. PROIEZIONE DELLA LUCE
   Pattern Etere + Luce → oggetto 4D
7. ESPERIENZA DELL'OSSERVATORE
```
