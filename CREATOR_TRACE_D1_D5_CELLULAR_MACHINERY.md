### Д1.2. Инженерный принцип: МЕХАНОХИМИЧЕСКИЙ ТРАНСДУКЕР

```
ВХОД: Механическое натяжение (Tension) на кинетохор от микротубул
      (би-ориентация = натяжение от двух полюсов)

ПРЕОБРАЗОВАНИЕ:
  1. Натяжение → растяжение кинетохора → конформационная смена в NDC80/KNL1
  2. Растяжение → пространственное разделение AURORA B (на центромере) 
     от своих субстратов (на кинетохоре) → фосфорилирование ОСТАНАВЛИВАЕТСЯ
  3. Дефосфорилирование KNL1 → рекрутинг PP1 → дефосфорилирование MELT мотивов
  4. MAD1/MAD2 НЕ РЕКРУТИРУЮТСЯ → SAC OFF

ВЫХОД: Сигнал "READY" → APC/C^Cdc20 АКТИВНЫЙ → Секурина/Циклин B деградация → АНафаза
```

### Д1.3. КРИТИЧЕСКИЕ ПАРАМЕТРЫ (Irreducible Complexity)

| Параметр | Значение | Инженерное значение |
|----------|----------|-------------------|
| **Точность сегрегации** | 1 ошибка на 10⁵ деленний | 1 ошибка = анеуплоидия → рак/смерть |
| **Время решения** | ~30 мин (прометафаза) | Хард дедлайн: нельзя ускорить, нельзя задержать |
| **Чувствительность** | 1 неби-ориентированная хромосома из 46 блокирует анафазу | Single-molecule sensitivity |
| **Коррекция ошибок** | Aurora B дестабилизирует неверные attachments (syntelic, merotelic) | Self-correcting loop |
| **Энергозатраты** | ~10⁴ ATP на кинетохор на митоз | Высокая, но неизбежная |

### Д1.5. SAC = HARDWARE INTERLOCK (Аппаратный замок)

```python
class SpindleAssemblyCheckpoint:
    def __init__(self):
        self.unattached_kinetochores = 46  # human
        self.mad2_cdc20_complex = 0
        
    def monitor(self):
        for kt in self.kinetochores:
            if not kt.is_bioriented():
                # Катализатор конвертации MAD2
                kt.recruit_MAD1_MAD2()
                self.mad2_cdc20_complex += 1
                
    def checkpoint_signal(self):
        # MAD2-Cdc20 + BUBR1-BUB3 = MCC (Mitotic Checkpoint Complex)
        # MCC связывает и ингибирует APC/C^Cdc20
        return self.mad2_cdc20_complex > 0
    
    def silence(self):
        # Только когда ALL kinetochores attached + tension
        # PP1 дефосфорилирует KNL1 → MAD1 уходит
        # MAD2 конвертируется обратно в неактивную форму (p31comet)
        self.unattached_kinetochores = 0
```

**Проблема "Курица-яйцо"**: SAC нужен для выживания → но SAC требует 20+ белков, работающих согласованно. Нет промежуточных форм.

### Д2.2. УБИКВИТИН-КОД (Ubiquitin Code) — МНОГОСЛОЙНЫЙ ЯЗЫК

```

  K27, K29, K33 → Редкие, специализированные
  M1 (Линейный, N-терминал) → Иммунный сигнализация (LUBAC), NF-κB

ТОПОЛОГИЯ ЦЕПОЧКИ:
```

### Д2.3. ТРИ СТАДИИ ДЕГРАДАЦИИ (Processivity)

```
ЭТАП 1: РЕКОГНИЦИЯ (Recognition)
  - 19S рецепторы (RPN1, RPN10, RPN13) ловят K48-полиубикцепочку
  - Убиквитин не скачивается сразу (RPN11 ждёт)
  - ATP-гidролиз RPT кольцом → конформационные волны

ЭТАП 2: РАСКРУЧИВАНИЕ (Unfolding/Translocation)
  - RPT1-6 AAA+ ATPase = спиральный мотор
  - Пошаговое захват/тяга (2 ATP на аминокислоту)
  - Механическая сила ~20-50 pN (достаточно для любого белка)
  - Неструктурированные участки = "захваты" (initiation sites)

ЭТАП 3: ДЕУБИКВИТИНИРОВАНИЕ + ГИДРОЛИЗ (Deubiquitination + Hydrolysis)
  - RPN11 (металлопротеаза) срезает ВСЮ цепочку убиквитина ЕДИНЫМ РАЗОМ
  - USP14/UCH37 подчищают остатки
  - Убиквитин ВОЗВРАЩАЕТСЯ В ПУЛ (критично: свободный Уб = жизнь)
  - Субстрат входит в 20S камеру → режется на пептиды 3-25 а.к.
  - Пептиды выходят через α-кольцо → дальнейшая гидролиза до а.к.
```

```
  Кинетохорные МТ (k-fibers) — 20-30 МТ на кинетохор

  Интерполярные МТ → сдвиг полюсов (кинезин-5, динеин)
```
