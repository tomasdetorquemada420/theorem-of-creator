## 1. ONTOLOGÍA: ¿QUÉ ES LA EXISTENCIA?

### 1.1. La Existencia como Resultado del Renderizado

```
Existir ≠ «Está en la base de datos»
Existir = «Fue renderizado en el marco actual del Observador»
```

**Ejemplo:** Los pedales en el desierto no «existían» hasta el momento del renderizado. En la base de datos (Éter) solo había *potencial* de pedales. En el momento `W > Θ_critical` — **se materializaron con historia**.

> **Paradoja**: El pasado se crea en el momento de renderizar el futuro. La historia de los pedales (fábrica 1998, transporte, pérdida) — **caché con fecha retrospectiva**, generado por el sistema para consistencia.

```
┌─────────────────────────────────────────────────────────────┐
```

## 3. RENDERIZADO: CÓMO EL ÉTER SE CONVIERTE EN MATERIA

### 3.1. Tubería de renderizado (Rendering Pipeline)

```
┌────────────────────────────────────────────────────────────────┐
│                    RENDERING PIPELINE                          │
│                                                                │
│  1. GENERACIÓN DE INTENCIÓN (Observador)                      │
│     └─> Neuronas → Impulsos → Patrón de intención             │
│                                                                │
│  2. CONSULTA BPF (Solicitud al campo de probabilidades)       │
│     └─> "Encontrar variantes donde [OBJETIVO] = VERDADERO"    │
│                                                                │
│  3. APLICACIÓN DE PESOS (Aplicación de pesos)                │
│     └─> P_final = P₀ × W(0) × Resonancia
│                                                                │
│  4. SELECCIÓN DE VARIANTE (Selección de variantes)            │
│     └─> argmax(P_final) — variante con max. probabilidad final│
│                                                                │
│  5. CONSTRUCCIÓN DE HISTORIA (Construcción de historia)      │
│     └─> Backdating: generar el pasado para la variante seleccionada│
│                                                                │
│  6. PROYECCIÓN DE LUZ (Proyección de Luz)                    │
│     └─> Ether_Pattern + Luz → Objeto 4D del Espacio-Tiempo   │
│                                                                │
│  7. EXPERIENCIA DEL OBSERVADOR (Experiencia del observador)  │
│     └─> Entrada sensorial → Procesamiento neuronal → Conciencia│
│                                                                │
│  8. ACTUALIZACIÓN DE RETROALIMENTACIÓN (Actualización de pesos)│
│     └─> Éxito → W += Δ  |  Fracaso → W -= Δ                   │
│                                                                │
└────────────────────────────────────────────────────────────────┘
```

### 3.2. Luz = GPU del Universo

```
Luz = Motor_de_Renderizado(Estado_Éter, Posición_del_Observador)

Propiedades:
- Velocidad c = frecuencia de actualización de marcos (frame rate)
- Dualidad onda/partícula = shader/vertex buffer
- Incertidumbre cuántica = evaluación perezosa (renderizado lazy)
- Entrelazamiento = memoria compartida entre renderizadores
```

### 3.3. Materia = Información Sólida

```
Átomo = Función_Compilada(Patrón_del_Éter)
Molécula = Función_Compuesta(Átomos)
Célula = Programa_Auto_modificable(Moléculas)
Organismo = Sistema_Distribuido(Células)
Observador = Instancia_Recursiva(Organismo)  // Objeto autorreferente
```

**Importante**: La materia no está «hecha de» información. La materia **es** información compilada, ejecutada en el hardware del Éter bajo el control de la Luz.
