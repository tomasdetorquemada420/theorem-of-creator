### 🔄 SYNAPTIC HOMEOSTASIS HYPOTHESIS (SHY) — TONONI & CIRELLI, 2003

**Hypothesis:** During wakefulness synapses strengthen (LTP) → saturation, noise, energy cost. During sleep (SWS) — global downscaling.

**Mechanism:**
```
Wakefulness:  LTP dominates → Σ synaptic weights ↑ → Energy ↑, Noise ↑, Saturation ↑
      ↓
SWS:           Slow oscillations (UP/DOWN) → Global LTD-scaling
      ↓
Awakening:    Σ weights ↓ to baseline → SNR ↑, Energy ↓, Learning capacity ↑
```

**Evidence:**
- EEG: slow wave amplitude ∝ prior wakefulness / learning
- Morphology: dendritic spines ↑ after wake, ↓ after sleep (mice, 2-photon)
- Molecular: Homer1a (activity-dependent) → metabotropic receptors → LTD in DOWN phases
- Energetics: ATP spent on ion pumping during wake, restored in sleep

### 🧠 GLYMPHATIC SYSTEM — "BRAIN'S LYMPH" (ILIFF, NEDERGAARD, 2012)

**Mechanism:**
```
Wakefulness: Astrocytes (AQP4) compressed → PVS space narrow → clearance slow
      ↓
SWS:           Norepinephrine ↓ → Astrocytes swell (AQP4 polarization) → PVS expands 60%
      ↓
CSF → Interstitium → ISF → Lymphatic vessels → Deep cervical lymph nodes
      ↓
Clearance:     Amyloid-β, tau, lactate, metabolites → 2x faster in sleep
```

**Clinical Significance:** Sleep disruption → Aβ accumulation → Alzheimer's (vicious cycle: Aβ disrupts sleep → worse clearance → more Aβ)

### 🌀 REPLAY / REACTIVATION — OFFLINE LEARNING

**Hippocampal-Neocortical Dialogue (Buzsáki, 1989; Wilson & McNaughton, 1994):**

```
SWS:
  Hippocampus (CA1) → Sharp Wave Ripples (SWR, 150-250 Hz, 50-100 ms)
      ↓
```

### 🧠 PREDICTIVE CODING / ACTIVE INFERENCE IN SLEEP (FRISTON, HOBSON, FRISTON 2012+)

**Theory:** Brain = generative model of world, minimizing free energy (surprise).
- **Wakefulness:** Perception = minimize prediction error via belief update (up) AND action (down)
- **Sleep (NREM):** Only belief update (priors) — no sensory input, no action → pure model learning
- **Sleep (REM):** Generate sensory data from model (top-down) without bottom-up correction → "hallucinations" = dreams

**Free Energy Principle in Sleep:**
```
F = E_q[log q(s) - log p(o,s)]  (Variational Free Energy)

Wakefulness:  min F by q(s|o)  (posterior given observations)
NREM:         min F by p(s)    (priors, world model) — no o
REM:          sample from p(o|s) ~ p(o) — generate "dream" data
```

### 💡 LUCID DREAMING (CONSCIOUS DREAMS) — META-COGNITION IN GENERATIVE MODE

**Neurobiology (Dresler, Voss, Hobson, 2009-2012+):**
- **DLPFC (Dorsolateral PFC)** — meta-cognition, working memory, self-awareness → **active in lucid REM** (normally off in REM)
- **Precuneus / PCC (Posterior Cingulate)** — self-awareness, DMN → activation
- **TPJ (Temporo-Parietal Junction)** — agency, theory of mind → activation
- **Gamma activity (40 Hz)** in fronto-temporo-parietal network → lucidity marker

**Induction Techniques:**

| Method | Mechanism | Efficacy |
|--------|-----------|----------|
| **MILD** (Mnemonic Induction) | Prospective memory + autosuggestion | ~20-60% after training |
| **WBTB** (Wake Back To Bed) | Wake after 4-6h sleep → 20-60 min wake → sleep | Boosts REM pressure |
| **RT / Reality Testing** | Habit of checking reality → transfers to dream | Basic hygiene |
| **Galantamine / Huperzine A** | AChE inhibitors → ↑ acetylcholine in REM | High, but pharmacological |
| **tACS 40 Hz** | Gamma entrainment in frontal lobes | Experimental, ~50-70% |

**Lucid = DLPFC engaged in REM generative model → Meta-model: "I am modeling, I am not in reality"**

**Phylogeny:**

| Taxon | Sleep | REM? | NREM? | Note |
|-------|-------|------|-------|------|
| **Cyanobacteria** | Circadian rhythms | — | — | KaiABC oscillator |

### 🌌 JAR (JARVIS / JUST-ANOTHER-ROUTINE) + SLEEP

**JAR Algorithm for Distributed Node Sleep:**

```
Each PX Node has:
  - sleep_pressure (adenosine analog): accumulates with each processed request/block
  - circadian_phase: synced via NTP/HTLC timestamp
  - sleep_window: daily window (e.g., 03:00-05:00 UTC ± jitter)

Algorithm:
  1. sleep_pressure > threshold AND circadian_phase ∈ sleep_window → INITIATE_SLEEP
  2. GRACEFUL_DRAIN: finish current tasks, transfer quorum responsibilities to peers
  3. OFFLINE_PHASE (NREM-analog):
     - Garbage collect DHT (expired keys, stale peers)
     - Compact local DB (LSM compaction, vacuum)
     - Retrain/local fine-tune ML models on accumulated data
     - Rotate keys, refresh certificates
     - Verify backups, merkle proofs
  4. REM_PHASE (optional, if ML-agent):
     - Generative replay: sample from local model, evaluate, self-correct
     - Dream up edge cases, adversarial examples
     - Update predictive world model
  5. WAKE_UP: reconnect, sync DHT, announce availability, reset sleep_pressure
  6. JAR: randomize next sleep_window ±30 min for network desynchronization
```

**Result:** Network never sleeps entirely (quorum always online), each node regularly "cleans its brain", models don't degrade.
