### 🧬 HORIZONTAL GENE TRANSFER (HGT) — LIFE'S P2P NETWORK

**Four Main Mechanisms:**

| Mechanism | Vector | DNA Size | Examples |
|-----------|--------|----------|----------|
| **Transformation** | Naked DNA from environment | Up to chromosome | *Streptococcus pneumoniae* (competence), *Acinetobacter*, *Neisseria* |
| **Transduction** | Bacteriophages | ~10-100 kb (packaging) | Generalized (any genes), Specialized (near prophage) |
| **Conjugation** | Plasmids (T4SS) | Up to 1-2 Mb (ICEs) | F-plasmid, R-plasmids (antibiotic resistance), Ti-plasmid (*Agrobacterium*) |
| **GTAs (Gene Transfer Agents)** | Virus-like particles | ~4-5 kb | *Rhodobacter capsulatus* — random genome fragments |

**HGT in Eukaryotes:**
- Endosymbiosis (mitochondria, plastids) → massive gene transfer to nucleus
- Phage/viral vectors (herpesviruses, adenoviruses, retroviruses)
- Transposons (LINEs, SINEs, DNA transposons) — autonomous HGT machines
- Animal HGT: *Bdelloid rotifers* (10% genome), aphids (carotenoids from fungi), nematodes (cellulases from bacteria)

### 🛡️ IMMUNE WAR: CRISPR, RNAi, INTERFERON, APOBEC

**Bacteria/Archaea: CRISPR-Cas (Adaptive Immunity):**
```
1. Adaptation: New spacer (phage fragment) → CRISPR array
2. Expression: pre-crRNA → processing → mature crRNA
3. Interference: crRNA + Cas (Cas9, Cas12, Cas13) → recognition + cut phage
```
- Memory passed vertically (CRISPR array)
- HGT: CRISPR-Cas themselves spread via plasmids/phages

**Eukaryotes: RNAi (RNA Interference):**
```
dsRNA (virus) → Dicer → siRNA (21-23 nt) → RISC (Argonaute) → cut viral RNA
```
- piRNA pathway (Piwi) — germline TE defense
- miRNA — endogenous regulation (co-opted viral machinery)

**Vertebrates: Interferon System (Innate Immunity):**
```
PRR (TLR3/7/8/9, RIG-I, MDA5, cGAS) → viral RNA/DNA
  ↓
Signaling cascade (MAVS, STING, TBK1, IRF3/7) → Type I IFN (IFN-α/β)
  ↓
IFN receptor (IFNAR) → JAK/STAT → ISG (Interferon Stimulated Genes)
  ↓
Hundreds of ISG: PKR, OAS/RNase L, Mx, IFITM, TRIM, APOBEC, SAMHD1, Tetherin
```

**APOBEC3 (Apolipoprotein B mRNA Editing Catalytic Polypeptide):**
- Cytidine deaminases: C → U in ssDNA (reverse transcription)
- Viral genome hypermutation (G→A) → non-infectious virions
- 7 human genes (A3A-A3H), expressed in lymphoid tissues
- HIV-1 Vif → APOBEC3G degradation (arms race)
