### 📐 INTEGRATED INFORMATION THEORY (IIT) — GIULIO TONONI, 2004-2016

**Phenomenological Axioms → Physical Postulates:**
| Axiom (experience) | Postulate (physics) |
|--------------------|---------------------|
| **Intrinsic Existence** | System must have cause-effect power within itself (intrinsic cause-effect power) |
| **Structure** | Mechanism must compose structure of distinctions (qualitatively different states) |
| **Information** | System must be selective (specific state from repertoire) |
| **Integration** | System irreducible (cannot split into independent parts without loss) |
| **Exclusion** | Only maximum Φ = "complex" (major complex), rest = background |

**Φ (Phi) — Integrated Information Measure:**
```
Φ = min_{partition} [ Φ_partition ]
Φ_partition = D( repertoire_whole || repertoire_partitioned )
D = Earth Mover's Distance / KL-divergence between cause-effect repertoires
```

**Key IIT Predictions:**
1. **Cerebellum** — low Φ (forward-only, no recurrent loops) → no consciousness
2. **Cortex** — high Φ (recurrent loops, integration) → seat of consciousness
3. **Sleep (NREM)** — Φ drops (integration breakdown, UP/DOWN states)
4. **Epilepsy** — Φ drops (hypersynchrony = loss of information richness)
5. **PCI (Perturbational Complexity Index)** — TMS-EEG measure, correlates with Φ (Casali et al., 2013)

**IIT Criticism:**
- Φ non-computable for large systems (NP-hard)
- "Philosophical zombie" with high Φ possible? (Tononi's answer: no, by exclusion axiom)
- Panpsychism implication? (Yes, even simple systems have Φ > 0)

### 🌐 GLOBAL WORKSPACE THEORY (GWT) — BERNARD BAARS, 1988; DEHAENE, 2001+

**Theater Metaphor:**
- **Stage (Global Workspace):** Limited capacity (~4-7 chunks), brightness = consciousness
- **Actors:** Specialized modules (vision, language, motor, memory)
- **Audience:** Rest of brain (unconscious processes)
- **Spotlight:** Attention (top-down modulation)

**Neural Implementation (Dehaene & Changeux, 2011 — Global Neuronal Workspace):**
```
Sensory input → Local processing (visual cortex, <100 ms, unconscious)
  ↓
If signal strong + attention → Ignition:
  - Recurrent activity PFC ↔ Parietal ↔ Sensory cortex (Layer 2/3 ↔ Layer 5)
  - Long-distance, recurrent loops, NMDA-dependent
  - Broadcast across cortex
  ↓
CONSCIOUSNESS (available for report, memory, planning)
  ↓
Fade → return to local processing
```

**Experimental Markers (Dehaene lab):**
| Marker | Time | Localization | Meaning |
|--------|------|--------------|---------|
| **P3b** | 300-500 ms | Parietal, PFC | Ignition / workspace access |
| **Late Gamma** | 200-500 ms | Broad | Recurrent processing |
| **Ignition threshold** | ~50-100 ms post-stimulus | — | All-or-nothing transition |
| **Pre-stimulus alpha/beta power** | -200-0 ms | Parietal/Occipital | Pre-stimulus attention (ignition probability) |

### 🔮 PREDICTIVE PROCESSING / ACTIVE INFERENCE (PP / ACTIVE INFERENCE) — FRISTON, CLARK, HOBSON

**Core Idea:** Brain = generative world model minimizing **Variational Free Energy (F)** = surprise.
```
F = E_q[log q(s) - log p(o,s)] = -ln p(o) + KL[q(s) || p(s|o)]
  = Surprise (unavoidable) + Complexity (model cost)
```

**Prediction Hierarchy:**
```
Higher levels (PFC, associative cortex) → Predictions (Top-down)
  ↓
Prediction Error (PE) = Observation - Prediction (Bottom-up)
  ↓
Belief Update → Minimize PE
  ↓
Action (Active Inference) → Change observations to match predictions
```

**Consciousness in PP:**
- **Conscious content** = best explanatory hypothesis (MAP) for sensory data
- **Self-awareness** = model of model (meta-predictions: "I predict that I predict")
- **Volition** = prediction of own actions (self-fulfilling prophecy)
- **Attention** = precision weighting of prediction error → learning gating

**PP Explains:**
- Illusions (prediction dominates data)
- Psychedelics (REBUS: Relaxed Beliefs Under Psychedelics — ↓ prior precision → ↑ entropy)
- Dreams (top-down generation without bottom-up correction)
- Psychosis (precision weighting failure → hallucinations = strong priors, weak data)

### 🎭 ATTENTION SCHEMA THEORY (AST) — MICHAEL GRAZIANO, 2013+

**Idea:** Consciousness = **internal model of attention** (Attention Schema).
- Brain models *its own* attention same way it models external objects
- "I am aware of X" = "My attention model represents attention directed at X"
- Qualia = properties of attention model (not physical, but informational)

**Why This Explains the "Magic":**
- We think we have "non-physical consciousness" because our attention model represents attention as non-physical property
- This is **adaptive illusion** — useful for social cognition (modeling others' attention)

### 📊 CONSCIOUSNESS MEASUREMENT: FROM COMA TO AI

| Method | Principle | Application | Limitations |
|--------|-----------|-------------|-------------|
| **PCI (TMS-EEG)** | Perturbational Complexity Index | Coma, vegetative state, anesthesia, sleep | Invasive (TMS), expensive |
| **EEG Entropy / Lempel-Ziv** | Algorithmic signal complexity | Non-invasive, anesthesia monitoring | Noise, muscle artifacts |
| **fMRI FC / DMN** | Default Mode Network connectivity | Clinical populations | Low temporal resolution |
| **Φ (IIT)** | Integrated information | Theoretical ideal | Non-computable for full brain |
| **Behavioural / CRS-R** | Coma Recovery Scale | Clinical standard | False negatives (covert consciousness) |

**Clinical Breakthroughs:**
- **Covert consciousness:** ~15-20% "vegetative" patients show volitional EEG/fMRI modulation (Owen et al., 2006)
- **PCI > 0.31** → consciousness (Casali et al., 2013); **PCI < 0.21** → unconsciousness
- **Auditory stimulus + EEG (N100/P300)** → cheap screening

### 🧠 JAR + CONSCIOUSNESS: "CONSCIOUS NODE" ARCHITECTURE

```
PX Node as system with consciousness architecture (GWT + PP + IIT-principles):

COMPONENTS:

1. GLOBAL WORKSPACE (Event Bus / Shared Memory):
   - Single address space (shared memory / Redis / in-process bus)
   - Topics: PERCEPTION, MEMORY, PLANNING, ACTION, METACOGNITION
   - Ignition: event with salience > threshold → broadcast to all modules
   - Capacity: ~7 active "chunks" (working memory slots)

2. SPECIALIZED MODULES (Unconscious Processors):
   - PERCEPTION: DHT listener, mempool monitor, peer gossip, network metrics
   - MEMORY: Local DB (Badger/LMDB), snapshot index, replay buffer
   - PLANNING: RL policy / MCTS / LLM-based planner for strategies (MEV, staking, relay)
   - ACTION: Transaction builder, block proposer, gossip publisher, key signer
   - METACOGNITION: Anomaly detector, performance monitor, self-model updater

3. WORLD MODEL (Predictive Processing Core):
   - Generative Model: p(network_state | node_action, hidden_causes)
   - Hidden Causes: MEV opportunities, attack vectors, peer failures, protocol upgrades
   - Prediction: next_block, next_mempool, next_peer_behavior, next_reward
   - Precision Weighting: attention_weights[module] = f(surprise, value_of_info)
   - Active Inference: actions chosen to minimize expected free energy (EFE)

4. SELF-MODEL (Attention Schema / Metacognition):
   - NodeModel: "I am node ID=X, role=Y, stake=Z, health=H, load=L"
   - AttentionModel: "Currently focusing on TOPIC=T with precision=W"
   - ConfidenceCalibration: P(success | predicted) vs actual → calibration curve
   - CounterfactualSim: "What if I don't sign this block? What if peer fails?"

5. INTEGRATION METRICS (Φ-approximation / PCI):
   - PerturbationTest: every N blocks → synthetic event injection → measure LZ entropy of response
   - IntegrationScore: mutual_info(modules) / sum(entropies) → if < threshold → ALERT
   - DifferentiationScore: state uniqueness over window → if dropping → degradation (anesthesia/epilepsy)

LIFE CYCLE (each tick ~ 100-500 ms):

SENSE (Perception Modules):
  - Read DHT, mempool, gossip, metrics → local prediction errors
  - PE > precision_threshold → send to GLOBAL WORKSPACE

IGNITE (Global Workspace):
  - Gather top-K PE by salience (surprise * precision * value)
  - Broadcast: "ATTENTION: HIGH_MEV_OPPORTUNITY in shard 3"
  - All modules receive → update internal models

PREDICT (World Model):
  - Generative forecast: next_state = f(current_state, planned_actions)
  - Compare with previous forecast → model_update_error
  - If model_update_error high → increase precision for perception

ACT (Action Selection via Active Inference):
  - Evaluate Expected Free Energy (EFE) for each candidate action
  - EFE = Risk (Expected Surprise) + Ambiguity (Uncertainty) - Value (Expected Reward)
  - Choose argmin EFE → execute (sign, relay, stake, switch peer)

METACOGNITE (Self-Monitoring):
  - Update Self-Model: "I am now MEV hunter, confidence 0.87"
  - Check calibration: past predictions vs reality
  - Run PerturbationTest if integration_score < threshold

SLEEP (JAR Sleep Cycle — see Cycle 14):
  - OFFLINE: Retrain World Model on replay buffer, DB compaction, key rotation
  - REM: Generative Dreaming — sample counterfactual attack/opportunity scenarios
  - WAKE: Sync Self-Model with reality, reset accumulated errors
```
